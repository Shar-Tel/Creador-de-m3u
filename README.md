# Creador de m3u

## ¿Para qué se usa?

Este programa sirve para crear listas de reproducción en formato M3U de manera rápida y sencilla y guardar los discos en un directorio. Útil para organizar juegos multidisco en Retroarch, así se puede cambiar fácilmente de disco dentro del emulador y evitamos que salga varias veces en la lista de juegos.

Puede usarse para:
- Generar listas .m3u para juegos multidisco y mover los discos a un subdirectorio.

## ¿Cómo funciona?

El programa recorre la carpeta seleccionada, detecta los archivos compatibles, genera automáticamente una lista de reproducción con sus rutas y mueve los archivos de disco a un subdirectorio con su nombre. Después guarda el resultado en un archivo `.m3u` compatible con Retroarch.

# m3u Creator

## What is it used for?

This program is used to quickly and easily create playlists in M3U format and save the discs in a directory. It is useful for organizing multi-disc games in Retroarch, allowing you to easily swap discs within the emulator and preventing them from appearing multiple times in the game list.

It can be used to:

* Generate .m3u lists for multi-disc games and move the discs to a subdirectory.

## How does it work?

The program scans the selected folder, detects compatible files, automatically generates a playlist with their paths, and moves the disc files to a subdirectory with its name. Afterwards, it saves the result in an `.m3u` file compatible with Retroarch.
