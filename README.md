# Creador de m3u

## ¿Para qué se usa?

Este programa sirve para crear listas de reproducción en formato M3U de manera rápida y sencilla. Se utiliza para organizar archivos de audio o video y convertirlos en una lista compatible con muchos reproductores multimedia.

Puede usarse para:
- Generar playlists desde una carpeta local.
- Reunir archivos multimedia en un único archivo M3U.
- Organizar colecciones de música o video.
- Compartir listas de reproducción con otros programas o dispositivos compatibles.

## ¿Cómo funciona?

El programa recorre la carpeta o carpetas seleccionadas, detecta los archivos compatibles y genera automáticamente una lista de reproducción con sus rutas. Después guarda el resultado en un archivo `.m3u` que puede abrirse en reproductores compatibles con este formato.

El proceso es sencillo:
1. Seleccionar la carpeta de origen.
2. Elegir la ubicación del archivo de salida.
3. Generar la lista de reproducción.
4. Abrir el archivo M3U en un reproductor compatible.

# M3U Creator

## What is it used for?

This program is used to create playlist files in M3U format quickly and easily. It helps organize audio or video files and turn them into a list compatible with many multimedia players.

It can be used to:
- Generate playlists from a local folder.
- Group multimedia files into a single M3U file.
- Organize music or video collections.
- Share playlists with other compatible programs or devices.

## How it works

The program scans the selected folder or folders, detects compatible files, and automatically generates a playlist with their paths. It then saves the result in a `.m3u` file that can be opened in players compatible with this format.

The process is simple:
1. Select the source folder.
2. Choose the output file location.
3. Generate the playlist.
4. Open the M3U file in a compatible player.
